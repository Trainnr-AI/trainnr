# sample

The one project a fresh clone carries (docs/76). Open it in the Studio
and the loop map shows every state missing with the first move named:
onboard a robot or ingest a recording. Anything a tool writes here is
gitignored — a project holds artifacts by hash, not source.

Point the tools at another project with `TRAINNR_PROJECT=<dir>`; make
one with the `create_project` MCP tool.
